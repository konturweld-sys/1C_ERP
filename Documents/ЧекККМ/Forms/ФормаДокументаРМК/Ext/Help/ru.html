Оформление чеков ККМ

Товары в табличную часть документа могут быть добавлены с использованием сканера штрихкодов или с использованием механизма ручного подбора товаров в документ. Для показа диалогового окна подбора необходимо нажать на кнопку Поиск.
Для увеличения скорости обслуживания клиентов предусмотрено использование горячих клавиш, а также дополнительной панели быстрых товаров. Горячие клавиши задаются в Настройках РМКА>
При подборе товара в табличную часть документа для товаров автоматически устанавливаются отпускные (розничные) цены. В качестве розничных цен склада используются цены, зарегистрированные для того типа цен, который указан в карточке того склада, с которого оформляется чек ККМ.
Если в Настройках РМКА> установлен флаг Менеджер торгового зала) то для каждого товара нужно указать продавца, ответственного за его продажу, при помощи команды Изменить продавца. Ответственный за данную продажу будет отражен в документе в колонке Продавец.
Для случаев, когда розничный склад делится на несколько помещений, в документе при оформлении продажи осуществляется автоматический подбор конкретного помещения, за которым числятся данные остатки. В случае необходимости по команде Изменить помещение кассир может посмотреть и оценить текущие остатки по всем имеющимся помещениям.
Возможность удаление и изменения позиций в чеке определятся настройками для кассира. Если для кассира не предусмотрены права, то требуется авторизация по карте старшего кассира с соответствующими правами.
При нажатии на любую из доступных команд оплаты (Оплатить наличными, Оплатить картой, и т.п.) будут автоматически применены действующие скидки. Для просмотра информации о том, согласно каким условиям была зарегистрирована та или иная скидка, нажмите на гиперссылку с суммой рассчитанной скидки в информационной панели или выберите соответствующую команду в контекстном меню табличной части Товары. Будет показан список тех скидок, которые применились для конкретного товара.
Расчет автоматических скидок необходимо проводить обязательно. Если скидки не рассчитаны, то чек не будет проведен.
Если в системе настроены скидки, назначаемые в ручную, то после нажатия на команду оплаты появляется диалоговое окно, в котором пользователь может назначить ручные скидки.
Если покупатель не готов совершить покупку после подбора товара, но планирует покупку позднее, то при переходе к новому чеку можно отложить оформленный чек. При этом товар можно зарезервировать по отложенному чеку. Товар можно зарезервировать только на тех складах, на которых включен контроль остатков товаров. Если для склада установлен вариант контроля остатков - Не контролировать, то зарезервировать товар в отложенном чеке нельзя. Отложенный чек в дальнейшем можно восстановить в РМК при помощи команды Продолжить чек, расположенной в меню доступному по кнопке Прочие операции.
Пробитие чека производится после оформления всех операций по оплате чека. Для пробития чека на фискальном регистраторе нажмите на кнопку Пробить чек.
По просьбе покупателя можно сформировать печатную форму Товарный чек командой Прочие операции - Товарный чек.

Особенность продажи алкогольной, табачной и маркируемой продукции

Для алкогольной, табачной и маркируемой продукции, по которой вступило в силу требование об указании кодов маркировки при розничных продажах, необходимо отсканировать код маркировки или акцизную марку с каждой единицы товаров.
При сканирование кода маркировки товаров, по которым действует разрешительный режим продаж, проверяется корректность кода и возможность продажи по данным ГИС МТ ("Честный знак") с использованием соответствующих технических средств.
Корректность указания кодов маркировки (акцизных марок) отображается в форме РМК пиктограммой зеленого или красного цвета.
Удаление и редактирование акцизных марок производится по команде Акцизные марки.
Для табачной продукции предусмотрен контроль МРЦ и ЕМРЦ. С даты начала контроля розничных цен на табачную продукцию (устанавливается в разделе НСИ и администрирование – Настройки НСИ и разделов – Продажи – Розничные продажи) автоматически цена продажи устанавливается равной значению МРЦ из кода маркировки и недоступна для изменения.

Оформление возвратов

Возврат может оформляться по ранее оформленному чеку или без указания основания. Оформить возврат на основании чека можно из формы РМК по кнопке Возврат по чеку.

Оформить возврат без указания основания можно из формы РМК по кнопке Возврат без чека.

В РМК по кнопке Возврат без чека сразу открывается форма оформления с пустой табличной частью Товары. В РМК по кнопке Возврат вначале открывается форма выбора ранее проданных товаров.

Закрытие смены


Документы вида Чек ККМ оформляются в течение кассовой смены. По окончании рабочего дня производится закрытие кассовой смены. При этом все документы Чек ККМ оформленные за день не удаляются, а остаются в информационной базе. Если в настройках параметров учета установлен флаг Архивировать чеки ККМ при закрытии кассовой смены, то документы архивируются.
При закрытии кассовой смены формируется и проводится обобщающий документы Отчет о розничных продажах и Отчет о розничных возвратах, которые подводят итоги розничной торговле по конкретной кассе ККМ.
